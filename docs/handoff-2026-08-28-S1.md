## Armadilhas que vão morder

- **Rota de assets.** `/api/mirrors/html` serve **um** ficheiro como string; o `index-v2.html:435-437` referencia `bridge.js` e `emotion-v2.js` por caminho relativo → **404**. Precisa de rota confinada (§2.3 do plano).
- **Build.** `CLAUDE.md`: qualquer alteração em `source/` exige `npm run build` + restart. Por isso os limiares de afinação vivem nos ficheiros servidos do disco ou em `~/.agentic-os/`, nunca no bundle do Next.
- **Silêncio.** O WASAPI **para de emitir buffers** quando nada toca — estado explícito obrigatório, senão a bola congela e parece bug.
- **Troca de dispositivo.** Plugar auscultadores mata a stream em silêncio. Watcher + restart, obrigatório na Fase 3.
- **Contrato não uniforme.** `mirrorball-D.html:758` **não tem** `setSkinAuto`. Não assumir API igual entre variantes.
- **Tetos visuais invioláveis:** 3 Hz, `beamIntensity` ≤ 0.18, greyscale, a bola não emite luz.
