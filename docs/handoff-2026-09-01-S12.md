## Achados dos researches que mudam o plano

**Perf (parte 1):** não há crise. **4,3 ms medidos de 17,5** → ~13 ms de margem livre. Maiores
ganhos: thin instances no mikado (672→6 meshes base), `freezeWorldMatrix` na sala/pilares, custo
do `refreshProbe`. **NÃO fazer**: compute shaders (escala ≤32k iterações não justifica, duplicaria
a lógica WebGL2/WebGPU), nem tocar no `music.js` para "acelerar" (50 Hz sobre ~20 escalares).
O maior custo GPU já visto no repo foi **+73 ms/frame por reatribuir uma `Color3`** — já corrigido.

**Realismo (parte 2):** o que falta não é geometria, é **luz e ar**. Quatro achados concretos:
1. **`scene.fog` nunca é chamado.** O "haze" é um escalar que multiplica intensidades — não há
   uma partícula de névoa entre a câmara e as paredes. Por isso os pilares do fundo têm o mesmo
   contraste que os da frente.
2. **Os dots são discos redondos** (`dots.js:44`, `CreateDisc`). Uma bola real projeta a **forma
   da faceta** — losangos. É o sinal mais imediato de "specular genérico".
3. **Exposição neutra** (`postExposure` default 1) quando um clube é escuro com picos brilhantes;
   `ColorCurves` existe no bundle e nunca é instanciada.
4. **Não existe `ShadowGenerator` em lado nenhum.** `receiveShadows=true` está declarado mas nada
   projeta sombra.

Fases R1-R4 custam **~0-0,3 ms**; só R5 (sombras) custa a sério (~0,3-1,0 ms/luz).
